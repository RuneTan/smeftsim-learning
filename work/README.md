# Local workspace

[English](README.md) | [简体中文](README.zh-CN.md)

`work/Material` contains working copies used to edit cards, export processes, generate events, and reweight them.
The download from [Ilaria Brivio's June 2023 SMEFTsim tutorial](https://github.com/IlariaBrivio/SMEFTsim_tutorial_June23) remains in `tutorial`; keep its provenance distinct from the working copies.

See [Material/README.md](Material/README.md) for individual files and scripts.
Only the project-written README files in this workspace are shared in the repository. Models, tutorial script copies, generated code, and events remain local.

Complete generated process directories are excluded from GitHub. To share a result, place selected compressed LHE files, ROOT files, plots, and metadata
in [examples](../examples/README.md), with the provenance of the inputs.
